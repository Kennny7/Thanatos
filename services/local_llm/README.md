# Local LLM Microservice

## Overview
The `local_llm` microservice provides lightweight, privacy-first local inference, interacting directly with local model runtimes such as Ollama and llama.cpp.

## Key Modules
- `ollama_client.py`: High-performance async client for querying local Ollama instances.
- `adapter_server.py`: OpenAI-compatible local server bridge.
- `prompt_builder.py`: Prompt formatter optimized for local open-weights models (Mistral, LLaMA, DeepSeek-Coder).
- `tool_parser.py`: Sanitizes and parses function calling arguments generated by local LLMs.

## Standalone Testing
Ensure dependencies are installed:
```bash
uv sync
```

To run Ollama sanitization and argument parser unit tests:
```bash
uv run pytest tests/unit/test_ollama_sanitization.py
```
